# Smart.Market

Free market intelligence, money calculators, a $100K paper-trading championship and fiduciary-advisor lead generation for **smart.market**.

Static HTML/CSS/vanilla JS with a tiny Python templater. No framework, no npm install.

## Structure

| Path | What it is |
|---|---|
| `src/partials/*.html` | Page content (16 pages + 404) |
| `src/assets/config.js` | **All go-live switches**: AdSense, GA4, form endpoints, Stripe links, YouTube IDs, affiliate links |
| `src/assets/app.js` | Every widget: market engine, screener, calculators, lead funnel, championship, donations, ads, consent |
| `src/assets/data.js` | Sample dataset (replace with a live feed in Phase 2) |
| `src/assets/styles.css` | Design tokens + components (light/dark) |
| `build.py` | Builds `dist/` (multi-page site with SEO meta, sitemap, robots, ads.txt) and `preview.html` (single-file preview) |
| `SMART-MARKET-BLUEPRINT.md` | Strategy, research on 28 sites, risks, phase-wise build prompts |
| `deploy/github-pages.yml` | Optional GitHub Pages workflow |

## Build

```bash
python3 build.py        # -> dist/ and preview.html
cd dist && python3 -m http.server 8000
```

## Deploy

- **Netlify / Vercel:** import this repo. `netlify.toml` / `vercel.json` already run `python3 build.py` and publish `dist/`.
- **GitHub Pages:** move `deploy/github-pages.yml` to `.github/workflows/pages.yml`, then Settings → Pages → Source: *GitHub Actions*. It builds and deploys on every push to `main`.
- Point `smart.market` DNS at the host.

## Go-live checklist

1. Fill `src/assets/config.js` (AdSense, form endpoints, Stripe links, YouTube IDs, affiliate links, GA4).
2. Put your AdSense publisher ID into `ads.txt` (generated by `build.py`, edit the template there).
3. Replace sample brokers in `data.js` with approved affiliate partners.
4. Make every editorial claim true or remove it (vetting, reviewers, methodology, prizes).
